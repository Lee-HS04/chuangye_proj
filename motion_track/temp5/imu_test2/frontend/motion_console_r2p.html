Setup guide

Protocols. "Quaternion (binary float32)" expects 16 bytes per notification: w,x,y,z as little-endian float32. "Text JSON/CSV" expects newline-terminated lines like {"w":1,"x":0,"y":0,"z":0} or w,x,y,z (roll,pitch,yaw in degrees also works as 3 CSV values).

Unknown hardware. Set a sensor's protocol to "Discover / Debug", declare its service UUID under Advanced, then Add Sensor. The log will list every reachable service/characteristic and stream raw hex so you can identify the right one and your data format.

Calibration. Assign each connected sensor to a body part, get into your reference pose (e.g. T-pose), then click Calibrate All — that pose becomes each joint's zero rotation.

Axis remap. If a limb rotates on the wrong plane, try the per-sensor axis remap — most IMU boards report a Z-up frame, this rig is Y-up.

Browser. Web Bluetooth needs Chrome or Edge on desktop/Android, opened as a real page — not Safari/Firefox, and not an embedded preview. If pairing fails when double-clicking the file, serve it locally: python3 -m http.server in its folder, then open http://localhost:8000/.
